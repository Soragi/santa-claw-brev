# Download your agent architecture

Open **Export**, then choose **Download team diagram · SVG**. Agent ZIPs also include `architecture/team.svg` and `architecture/team.json` at the archive root. Open the SVG in a browser to zoom or print to PDF.

The overview uses saved configuration: Santa Claw is the orchestrator; Snow Inspector independently reviews delegated results. Each deployed, non-exported Claw lists its name, role, enabled tools, selected library skills, custom skill names, and configured Post Office/customer MCP scopes. Hidden deployed Claws are included; drafts and departed Claws are excluded. Resetting changes future downloads, not files already downloaded.

Solid green lines represent orchestration; the dashed connection represents review. This is a configuration overview, not evidence of live collaboration or authorization. OpenShell still enforces execution/network access. OpenClaw exports create their own manager/specialist/reviewer arrangement. Hermes exports import an authored profile whose native tools and delegation need destination setup. The overview describes the workshop team before migration.

Prompts, skill instructions, knowledge, chats, credentials, model endpoints and approval capabilities are omitted. User-authored names remain: inspect before sharing. Configure destination models, credentials, tools and policies separately.
